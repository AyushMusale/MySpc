# Spaces

## Overview

A **Space** is a persistent communication environment designed for a group of people with a shared purpose. Unlike a traditional group chat, a Space organizes conversations, voice communication, and shared resources into dedicated channels, allowing information to remain structured and easy to discover over time.

A Space can represent:

* 👨‍👩‍👧‍👦 Family
* 👥 Friend Circle
* 🎓 College Class
* 💼 Startup Team
* 🎮 Gaming Squad
* 🌍 Public Community

---

## Goals

* Organize communication instead of mixing everything into a single chat.
* Reduce information loss.
* Enable seamless switching between text, voice, and video communication.
* Keep important files and documents accessible.
* Create a persistent digital space where members can collaborate or socialize.

---

## Features

### Text Channels

Dedicated channels for textual communication.

#### Features

* Rich text messaging
* GIF support
* Emoji reactions
* Stickers
* Images & Videos
* File attachments
* Message replies
* Threaded conversations

### Voice Channels

Persistent voice rooms that members can join or leave at any time without initiating a traditional phone call.

#### Features

* Drop-in voice communication
* Push-to-talk
* Voice activity detection
* Noise suppression
* Screen sharing
* Participant controls
* Voice recording *(Future)*

---

### Video Channels

Dedicated channels for video communication.

#### Features

* Camera sharing
* Screen sharing
* Live streaming
* Multiple participants
* Participant moderation

---

### Documents Channel

A centralized repository containing all documents shared within the Space.

Unlike traditional chat applications where documents become buried inside message history, the Documents Channel keeps them organized and searchable.

#### Features

* Automatically indexes uploaded documents
* File previews
* Search
* Sorting
* Folder organization *(Future)*
* Version history *(Future)*

---

### Media Gallery *(Future)*

A centralized gallery containing images, videos, and GIFs shared across the Space.

#### Features

* Image gallery
* Video gallery
* Search
* Filters
* Albums *(Future)*

# Private Chats

## Overview

Private Chats provide secure one-to-one communication between users.

Unlike Spaces, Private Chats are intended for personal conversations and remain isolated from group environments.

All messages are protected using **End-to-End Encryption (E2EE)**.

# Design Philosophy

Traditional group chats place every conversation inside a single message stream, causing important discussions, files, and announcements to become difficult to locate over time.

**Spaces** solve this by organizing communication into dedicated channels for text, voice, video, and documents while maintaining the simplicity and familiarity of a group chat.

The objective is **not** to replace messaging with complexity, but to provide a structured communication environment where groups can collaborate, socialize, and share information without losing context.
